# การ์ดเชิญงานมงคลสมรส — ลูกหมู ♥ นุ๊ก

การ์ดเชิญออนไลน์ของ **นนท์ชนก เพ็ชรสุ่ม (ลูกหมู)** และ **กิตติพจน์ กิจขจรไชยกุล (นุ๊ก)**

- **วันงาน** วันอาทิตย์ที่ 20 ธันวาคม 2569
- **สถานที่** สมาคมธรรมศาสตร์ ในพระบรมราชูปถัมภ์
- **กำหนดการ** 09:09 น. พิธีหมั้น · 11:00 น. รับประทานอาหาร
- **Dress code** Pastel colors

## ไฟล์

`index.html` — การ์ดทั้งใบอยู่ในไฟล์เดียว รูปพรีเวดดิ้งและโลโก้ฝังเป็น data URI
ไม่มีไฟล์แนบภายนอก ดับเบิลคลิกเปิดได้เลย หรือวางบนโฮสต์ไหนก็ได้

ต่อเน็ตเฉพาะฟอนต์จาก Google Fonts เท่านั้น

## แก้ไข

แก้ `index.html` ได้ตรง ๆ ทั้ง HTML/CSS/JS อยู่ในไฟล์เดียว จุดที่มักต้องแก้:

| อยากแก้ | ค้นหาคำว่า |
| --- | --- |
| เวลาในกำหนดการ | `class="sched"` |
| ลิงก์ฝากคำอวยพร | `fillio.so` |
| ลิงก์แผนที่ / ปฏิทิน | `class="actions"` |
| สี dress code | `class="swatches"` |
| วันนับถอยหลัง | `2026-12-20T09:09` |
